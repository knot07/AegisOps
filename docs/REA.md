# REA 按需安装

主包不再内置 REA、Ghidra 或 JDK 离线运行环境。未安装时，在应急样本区域点击安装入口，通过 Atlas 发起单次授权的固定安装任务；进度和日志可查询，环境自检通过后才会标为可用。

当前隔离 worker 需要 Linux x64 / WSL2 及网络命名空间相关权限。普通用户或原生 Windows 后端不能直接运行该 worker；可将工作台部署到符合条件的 WSL2/Linux 环境。Windows 主工作台其他功能独立可用。

安装器从固定官方地址下载并校验 Node、JDK、Ghidra；缓存已校验文件，避免重复下载。REA 用于静态逆向，不执行样本。使用实际工具证据和反编译结果，不把模型生成文本冒充真实逆向输出。
