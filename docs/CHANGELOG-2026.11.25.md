# 2026.11.25 · 调度可追踪，工作台交互升级

## 任务中心与 Worker

- 任务中心触发的工作流按执行尝试关联节点记录，可查看已运行节点、失败位置和错误信息。旧执行不会补写历史。
- 对话右侧展示 Worker 的真实执行状态，可打开卡片查看工具步骤和结果；对话中的 Worker 卡片共用详情和状态样式。
- 区分定时触发和「立即运行」；停用或归档后不再显示下次运行，恢复后重新计算。内置任务归档后不会被同步重新创建。
- 任务变更写入结构化审计日志；终态执行可在任务中心标为已读。事件触发支持进程内并发限额与有界排队，满载时按策略拒绝或淘汰旧等待项。此版本不把它作为跨实例队列，也不承诺新增外部通知渠道。

## 工作台界面

- 用户消息、对话步骤与 Worker 结果采用分层卡片。运行步骤向下扫光，完成步骤保留高亮；流程点与对应图标共用状态色。
- 首页成功率换为刻度表盘和轻量呼吸动画。登录页增加流动背景和状态过渡，支持暂停及系统减少动态效果设置。
- 统一任务、技能、工作流、工具清单及对话的小图标，并补齐对话添加菜单、Build/Plan/Goal、知识集和历史栏操作图标。
- 修复通道「保存」与「重启连接」的按钮对比度。Worker 状态和详情操作使用当前皮肤的可读强调色，与浅色按钮底色分开。
- 首页、工具和场景均不再挂载二次元人物；未发行实验性的壁纸和人物素材。Atlas Agent、Worker 和品牌标识不变。

## 应急响应与情报

- 应急响应报告区明确区分已返回条数、确认截断、仅首批以及覆盖未知，避免把部分日志当作完整覆盖。
- 整理威胁情报来源别名和去重逻辑，区分安全资讯与可用于资产匹配的漏洞公告；刷新正式及演示研判页的内置构建。

## 下载和升级

- **Windows 10/11 x64**：解压 `Windows-x64.zip`，运行 `start.cmd`。首次启动需要联网准备主要依赖。
- **Linux / WSL2**：解压 `Linux.zip`，按 `DEPLOY.md` 运行 `bash install.sh`。
- **二次开发或托管在线更新**：使用 `Source.zip`，内含预构建前端。核心依赖锁与 2026.11.19 保持一致；升级前仍应备份数据目录。
- 使用 `SHA256.txt` 核对下载完整性。包内没有预设账号或运行数据。
