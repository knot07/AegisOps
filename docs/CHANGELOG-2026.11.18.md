# AegisOps 2026.11.18 更新说明

这次把“情报 → 资产核查 → 漏洞整改”接入现有运营闭环，并完成应急取证、工作流与界面的一轮统一。

## 威胁情报与资产联动

- 新增威胁情报工作空间，首页只展示七个来源入口，具体公告进入来源后查看。
- 平台自行采集微步、阿里云、斗象、长亭、NVD、Tenable、CISA 的公开接口、网页或官方订阅，不再下载第三方发布的数据库。
- 增加分来源采集状态、失败保留、分页重试、去重增量入库，保留已有情报 ID 与整改关联。
- 日期、风险和关键词筛选保留；英文公告可辅助翻译并对照官方原文。
- “Atlas 核查”使用专属品牌图标和独立分析引导，结合真实资产产品、版本和公告核实适用性。
- 增加原生只读核查工具与技能，产品关键词匹配仅作为线索，不自动判定漏洞存在或新建资产。
- 每日更新工作流同步改为直采、入库、资产匹配。默认关闭，原有开关和时间设置保持不变。

## 应急响应与样本分析

- Solar 不再作为一块独立操作区展示，改为授权 AI 调查背后的辅助取证工具。
- Linux SSH 调查调用已校验的官方固定脚本，归档原始报告包、文本、文件清单及 SHA-256，然后交由 AI 关联分析。
- Solar 权限、网络或采集异常会记录并保留已有证据，继续有限调查，不报告虚假的完成状态。
- Windows 主机调查继续使用 WinRM HTTPS 固定模板；不宣称具备 Solar 图形工具后台调用能力。
- REA、Ghidra、JDK 不再塞入主包；按需安装，实际进度和环境自检可查询。隔离 worker 当前需要 Linux/WSL2。

## 界面与修复

- 统一场景按钮、搜索、日期筛选、字体、卡片尺寸与浅色主题。
- 模型用量详情改为紧凑的数据卡片，说明默认折叠，删除旧的外部“模型用量”入口。
- 修复资产登记参数在刷新和保存后重复打开弹窗的问题；跳转只消费一次。
- 工作流按钮文案统一为 Atlas，发布引导替换为品牌图标；移除工作流详情的红色拖拽调宽条。
- GitHub 主页面重写，26 张页面截图均为本版重新拍摄，旧图库替换。

## 部署与兼容

- Release 维持 Linux、Windows x64、Source 三个主包及校验清单。
- Windows 保留基础 Python、Git 与安装引擎，主要依赖首次启动自动安装到私有目录；中断后可重试，本地缓存复用。
- 首次部署自行创建管理员，不提供默认密码。包中不带业务数据、聊天记录、API Key 或设备登录凭据。
- 核心依赖锁文件与上一版保持兼容；已有用户更新请保留并备份原数据目录。

采集来源可能因网络、访问限制或结构变化而暂不可用，页面按来源显示实际结果。Docker 未在本轮重建验证；真实业务主机和企业沙箱外发不属于本次发行测试范围。
