# 2026.11.19 · 主题皮肤与工作台体验升级

## 主题与界面

- 新增海盐蓝、青岚、暮紫、暖砂四款皮肤，保留经典森绿；每款支持浅色、深色和跟随系统，选择自动保存。
- 统一首页、任务中心、漏洞运营与应急响应的按钮、筛选项、日期选择、卡片背景和字体层级；厂商标识与风险语义颜色保留。
- 重做深色表面与文字层级，修复设备配置、工具详情、模型管理及场景弹窗中的白底与对比度问题。
- 研判正式平台和演示平台只让“汇总攻击卡”和“外网攻击趋势区”的两块背景跟随皮肤；坐标轴、柱形、折线、环形图与图例保持原配色。
- 侧栏主题入口更换为调色盘图标。
- 对话用户头像与管理员身份图标统一，消息强调文字采用主题色；完善对话步骤、插件详情和目录的样式。

## 模型与实际运行参数

- 模型编辑与对话模型管理统一品牌图标、主题配色和上下文刻度控件。
- 对话模型选择器拓宽，显示完整模型名称与已保存的思考强度。
- 上下文设置传递到模型运行配置，补充相应回归验证；思考强度按模型能力配置，不代表所有供应商都支持同一组参数。

## 修复与默认配置

- 修复刷新工具时场景插件和 REA 插件重复注册路由产生的警告；保留正常的路由冲突检测。
- 修复只读技能状态查询时对缺少版本管理信息的包的处理。
- 移除旧的内置 Daily Threat Intelligence 定时任务模板；新部署不再生成。现有部署已创建的任务可在任务中心手动删除。
- 保留“威胁情报 · 每日同步与资产匹配”的可选能力，首次启用仍由用户决定。

## 下载与部署

- Release 提供 Linux、Windows x64、Source 三个主包和 SHA256 校验清单。
- 首次部署自行设置管理员，无默认账号密码；包内不含业务数据、聊天记录、设备凭据或模型密钥。
- REA 与大型逆向运行环境保持按需安装。Windows 首次启动联网下载主要依赖，依赖保存在项目私有目录。
- 核心依赖锁与 2026.11.18 保持一致，支持符合条件的托管安装在线升级；升级前备份并保留原数据目录。

具体测试范围与限制见 [发行验证](RELEASE-VERIFICATION.md)。
