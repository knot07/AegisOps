# AegisOps 2026.11.26 · 日期联动与深色体验修复

- **漏洞运营**：日期筛选同步更新「漏洞发现与关闭趋势」的实际数据、横轴、总量和日均。30 天按日显示，长区间分组汇总，不再截掉前面的日期。曲线进入视野时从左到右展开，关闭线使用与新增线区分的颜色，支持系统「减少动态效果」。
- **首页**：「任务脉搏」选择 24 小时、7 天或 30 天后，下方执行量与成功率使用相同区间。补齐首页与部分工作场景的英文显示。
- **应急响应**：默认进入事件台账，事件详情按调查步骤分区。优化调查动态、时间与 IP 的显示，并修复未生成报告时深色界面的白底。
- **主题与交互**：任务执行列表、筛选、弹窗和对话菜单适配主题；模型供应商选择和编辑保留厂商品牌标识。风险等级和任务状态继续用独立的语义色区分。

## 下载与升级

- **Windows 10/11 x64**：下载 `Windows-x64.zip`，解压后双击 `start.cmd`。首次启动需要联网准备依赖。
- **Linux / WSL2**：下载 `Linux.zip`，解压后按 [部署与操作](../DEPLOY.md) 运行 `bash install.sh`。
- **托管在线更新 / 二次开发**：使用 `Source.zip`，内含预构建前端。核心依赖锁与 2026.11.25 一致；安装或更新前建议备份数据目录。
- 下载后可用 `SHA256.txt` 校验。软件包不含本机账号、配置或演示数据库。
