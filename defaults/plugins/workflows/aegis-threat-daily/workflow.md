# 每日情报同步与资产匹配

在威胁情报页面启用，默认关闭。任务中心统一定时调度，沿用已设置的执行时间与授权账号。

1. 直接访问微步、阿里云、斗象、长亭、NVD、Tenable、CISA 的公开接口、网页或官方订阅源。本平台自行解析，不下载 GitHub 上发布的情报数据库。
2. 分来源校验、去重并增量更新，保留原记录 ID、原文链接与关联整改记录。记录每个来源的成功时间、条数和失败原因。
3. 个别来源不可用时，保留该来源历史记录并明确标记本次未更新；其他来源继续采集。全部失败则本轮失败并停止后续匹配。
4. 匹配近30天情报与已登记软件产品和版本，仅生成待核实线索。产品名称匹配不能证明存在漏洞；人工确认后转入漏洞整改、复测、归档。

英文情报保留原文，页面中文译文由模型辅助生成。更新任务不会主动扫描资产或自动确认漏洞。
